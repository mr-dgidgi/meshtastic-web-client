# meshtastic-web-client
meshtastic web client container

It allow you to host your own Web client if you operate offline.
The map feature will not work if you are offline as it use openstreetmap service.

## Docker hub : 
[mrdgidgi/meshtastic-web-client](https://hub.docker.com/repository/docker/mrdgidgi/meshtastic-web-client)

## Run the container : 
`docker run -d -p 80:80 mrdgidgi/meshtastic-web-client:2.7.1`
